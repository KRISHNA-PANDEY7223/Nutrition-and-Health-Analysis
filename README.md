# 🥗 Nutrition and Health Analysis

## 📌 Project Overview

This project focuses on analyzing nutrition and health-related data to understand how dietary habits, calorie intake, activity levels, and lifestyle factors influence overall health outcomes. The goal is to identify key patterns that affect nutritional well-being and provide data-driven insights into health status.

The analysis is performed using Python and focuses on exploratory data analysis (EDA) techniques and visualizations.

---

## 📊 Dataset Description

The dataset contains nutritional and health-related attributes such as:

- Calorie intake  
- Dietary habits / Diet type  
- Activity level  
- Health indicators  
- Nutritional status variables  
- Lifestyle-related factors  

---

## 🎯 Objectives

- Analyze relationships between calorie intake and health outcomes  
- Understand the impact of dietary habits and diet type on nutritional status  
- Study how activity levels influence overall health  
- Identify patterns affecting overall well-being  
- Explore correlations between health-related variables  
- Generate insights using visual analytics  

---

## 🔍 Exploratory Data Analysis (EDA)

The following analysis techniques were used:

### 📦 1. Distribution & Outlier Analysis
- Boxplots were used to detect outliers in nutritional and health variables  
- Helped identify extreme values in calorie intake and other health indicators  

---

### 🔥 2. Correlation Analysis
- Heatmaps were used to visualize relationships between variables  
- Helped identify strongly correlated health and nutrition features  

---

### 📈 3. Relationship Analysis
- Regression plots (regplot) were used to study trends between:
  - Calorie intake vs health indicators  
  - Dietary habits vs health outcomes  
  - Activity level vs health status  

---

### 📊 4. Comparative Analysis
- Scatter plots were used to explore relationships between variables  
- Stacked bar charts were used to compare categorical health outcomes across groups  
- Count plots were used to analyze distributions across:
  - Diet types  
  - Activity levels  
  - Health categories  

---

### 📉 5. Trend Analysis
- Line plots were used to observe trends and patterns across continuous variables  
- Helped in understanding how nutritional and health factors change across different conditions  

---

## 📌 Key Insights

- Calorie intake shows a noticeable relationship with overall health status  
- Diet type plays a significant role in determining nutritional outcomes  
- Activity level has a strong influence on health and wellness indicators  
- Certain dietary habits are strongly associated with better health outcomes  
- Outliers in calorie consumption indicate extreme dietary patterns  
- Visual analysis helps uncover hidden patterns across lifestyle and nutrition factors  
- Combining diet type and activity level provides deeper insights into health status
